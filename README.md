# AURORA LANCE — 오로라 랜스

브라우저에서 바로 하는 세로 탄막 슈팅 게임 (PC·스마트폰).

**플레이: https://sjidok750-creator.github.io/aurora-lance/**

- PC: 방향키 이동 · Z 사격 · Shift 집중 · X 폭탄 · C 오버드라이브 · Esc 일시정지 (게임패드 지원)
- 스마트폰: 화면을 끌어서 이동(자동 사격), 아래 FOCUS · BOMB · O.D 버튼. 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 전체 화면 실행.
- iPhone 은 무음 스위치가 켜져 있으면 소리가 나지 않습니다.

3D 기체는 Blender 로 렌더, 그래픽은 WebGL2, 음악·효과음은 Web Audio 실시간 합성.
안내 음성은 Supertonic 3(OpenRAIL-M)으로 만든 **AI 합성 음성**입니다.
